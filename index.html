Portfolio

This portfolio includes GIS projects focused on QGIS workflows, Python scripting, spatial databases, OpenStreetMap analysis, and Leaflet web mapping. These projects demonstrate practical geospatial problem solving across desktop GIS, database GIS, and web GIS environments.

QGIS Foundations and Workflow Automation

This project focused on core open-source GIS workflows in QGIS, including projections, joins, raster and vector analysis, OpenStreetMap workflows, spatial queries, and automation using the QGIS Processing Modeler.

Python GIS Automation

This project introduced Python scripting for GIS workflows, emphasizing automation, geoprocessing, spatial data handling, and repeatable GIS task execution.

PostGIS Spatial Database Project

This project focused on building and managing a spatial database using PostgreSQL and PostGIS inside a Docker environment. It explored spatial SQL, database orchestration, and relational spatial analysis.

OpenStreetMap and PostGIS Spatial Analysis

This project used OpenStreetMap data and PostGIS to perform spatial analysis and database-driven GIS workflows. Alaska was used as the primary study area for querying and analyzing OSM spatial datasets.

Web GIS and Leaflet Interactive Mapping

This project built an interactive web map using Leaflet, JavaScript, HTML, CSS, and GeoJSON. The map displays Knoxville breweries, parks, and greenways.

Live Knoxville Breweries, Parks, and Greenways Map

This live GitHub Pages web map demonstrates interactive web GIS deployment using Leaflet and local Knoxville GeoJSON datasets.

About Me

I am a GIS Analyst at Knoxville Utilities Board with experience supporting utility operations, spatial analysis, mobile GIS workflows, and geospatial data automation. I am currently pursuing a Master of Science in Geographic Information Systems Technology at the University of Arizona, where I have focused on open-source GIS, spatial databases, Python automation, and web GIS development.

My technical interests include GIS automation, spatial databases, drone mapping workflows, LiDAR applications, and building scalable geospatial systems that combine analysis, visualization, and operational efficiency.

Core skills: ArcGIS Pro, ArcGIS Online, QGIS, Field Maps, Survey123, ArcGIS Dashboards, Experience Builder, Python, ArcPy, SQL, JavaScript, HTML, CSS, PostgreSQL, PostGIS, Docker, OpenStreetMap, GeoJSON, and Leaflet.js.
